## Why it is written that way

The first line is a result, not a category. "An agent bought something" is
checkable; "infrastructure for the agent economy" is not.

The second line is the actual claim and the only surprising sentence in it.
It gets its own line because it is what makes someone stop.

No emoji ladder, no thread, no "excited to share". The work is unusual
enough to be stated plainly, and plain reads as confident next to the
launch-post house style.
